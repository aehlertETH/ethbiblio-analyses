# Web of Science input data

The Web of Science exports used by
`assets/X_X_wosOpenalexClassificationCompare` are not distributed in this
repository. Obtain and use those data only under terms that permit the
intended use.

To run that asset manually, place the approved source exports in the same
institution-specific layout used by the script. The all-assets runner excludes
this asset so that the public package remains runnable without these files.
